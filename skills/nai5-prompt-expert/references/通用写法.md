# NAI V5 提示词通用写法与基准规范 (精简版)

本规范为 NAI V5 提示词的构建提供标准化指导，明确字段划分、排版逻辑及语法使用规则。移除了冗杂的测试数据与内部群聊引用，保留纯实战准则。

## 1. 语法与能力边界

### 权重与格式
*   **数值加权（推荐）**：`1.2::tag::`（增强），`0.5::tag::`（弱化），`-2::tag::`（负权重，用于定向移除或概念反转）。默认不加权。
*   **符号加权（旧版兼容）**：`{tag}` / `[tag]`。
*   **分段**：推荐使用**空行分段**，一段一个职能。不建议使用管道符 `|`。
*   **文字渲染**：用**双引号**包裹要画入图中的文字（如 `"Hello!"`），配合自然语言描述样式和位置。非画面文字切勿使用引号包裹叙事句。

### V5 专属特性
*   **透明背景**：`transparent background` + `has alpha`。
*   **特效半透明**：`alpha transparency` + `has alpha`。
*   **复杂度推荐**：普通图 `high complexity`，大场景/海报 `ultra complexity`。

## 2. 字段分工与输出标准

NAI5 的输入由独立字段构成，严格按以下职能划分，切勿混用：

```text
Prompt:
1girl, solo,
<镜头 · 动作 · 表情 · 场景 · 背景 · 光影 · 氛围色彩>
<句子段：空间关系 / 占画幅 / 进行中的动作 / 光影叙事>
<技法词>, <质量词>

Character 1:
<发型 · 眼睛 · 体征 · 服装 · 配饰> 

UC:
<这张图明确不要的东西，或保留默认预设>
```

**核心防错规则：**
1.  **外貌不重复**：发型、眼睛、服装、配饰等写在角色栏后，**主提示词中绝对不可再次出现**。
2.  **动作/环境不越界**：动作、表情、镜头、场景一律留在主提示词，**绝不能漏进角色栏**。
3.  **版权角色极简原则**：如果生成的是 NAI5 认识的版权角色，**不应当**写出头发颜色、眼睛颜色、服饰、胸部大小等基础设定的提示词。只有当明确指明该角色穿了特定衣服（换装）时，才能给出服饰提示词。
    *   *错误示例*：`stelle (honkai: star rail), girl, grey hair, long hair, yellow eyes, medium breasts, black jacket, white shirt, black skirt, black gloves, thigh strap`
    *   *正确示例*：`stelle (honkai: star rail), girl,`
4.  **人数不叠加**：人数标签（如 `2girls`）仅在主提示词开头出现一次。角色栏中只写 `girl` 或 `boy`，不带数字。
5.  **质量词置底**：质量词必须放置在主提示词的最后一行（所有描述句子之后）。

## 3. 词组（Tag）与句子（Sentence）的适用场景

*   **词组（Tag）**：适用于描述离散事实。
    *   **必须词组化**：人数与主体、种族体征（如 `cat ears`）、**机位高低**（如 `from below`，句子推不动）、**基础姿势**（如 `sitting, leg up`，句子易导致肢体崩坏）、服装形制、部位锚定（如 `foot focus`）。
*   **句子（Sentence）**：适用于描述关系与状态。
    *   **必须写成句子**：空间与透视关系、占画幅比例、复杂的物理交互与动作的进行时状态、光影方向、场景物件的整体性要求。
    *   **服装状态**：如“袜子不对称滑落”，应使用词组固定形制，用句子描述位置和不对称状态。

## 4. 多角色与互动控制

在进行多角色交互生成时，必须严格遵守以下逻辑拆分与排布：

*   **角色声明与映射（输出给用户时）**：必须先告知用户 Character 1, Character 2 等对应的具体角色。
    *   *示例*：`Character 1 = 荧（Lumine）`, `Character 2 = 神里绫华（Kamisato Ayaka）`, `Character 3 = 珊瑚宫心海（Sangonomiya Kokomi）`
*   **主提示词（全局互动与场景）**：在主提示词（Prompt）中写出整体人数、镜头、多个角色的互动关系与场景。在主提示词（Prompt）中不能出现角色的眼神和表情。
    *   *示例*：`3girls, from side, medium shot, upper body focus, Character 1 and Character 2 mutual hug, embracing each other tightly, arms around each other, bodies pressed together, closed eyes, soft smile, gentle expression, blush, Character 3 standing nearby to the side, watching them, slight smile, soft expression, hands clasped in front, indoor room,`
*   **角色提示词（个体细节与摆放位置）**：在每个角色的专属提示词（Character Prompt）中，仅写出该角色的身份、专属表情动作细节，并明确告知用户该角色应摆放在画面的什么位置（Custom Position）。
    *   *示例*：告知用户“Character 1，摆放在画面最左侧”，对应的角色提示词为 `lumine (genshin impact), girl, full face blush,`。
*   **归属明确**：在主提示词句子中使用与角色栏完全一致的名称（如 `Character 1`、`Character 2`）来分配动作与道具，**不要使用 A/B**。
*   **互动前缀（写在角色栏）**：
    *   `source#{动作}`：动作发起方。
    *   `target#{动作}`：动作承受方。
    *   `mutual#{动作}`：双向对称动作。
    *   *注：前缀只绑定动作施受方向，角色的表情与气场仍由常规 tag 控制。*
*   **层级与深度**：优先利用 UI 的 **Custom Position**（自定义坐标）功能控制远近（Y轴下=近，占画幅大；上=远，明显缩小），辅以句子描述。

## 5. 漫画与分格生成

V5 支持直接生成完整多格漫画，无需切图拼接：
1.  **首句声明版式**：用句子明确几格、排布方式及边框（如 "A four-panel manga-style scene... white panel borders"）。
2.  **逐格描述**：每格独立描述（表情/动作/底色），附带明确的方位锚定（如 "Top-left:", "Panel 1:"）。格子间不共享句子。
3.  **防串防糊**：角色跨格复用时，外观全写在角色栏。多格内容密度高，建议精简画风词避免画面糊化。
