## 3. 常见问题解答 (FAQ)

### 3.1 部署相关
- **Q: 启动服务时报错 `Port 8080 already in use` 怎么办?**
- **A**: 检查端口占用情况 `netstat -ano | grep 8080`，修改 `application.yml` 中的 `server.port` 配置。

### 3.2 业务相关
- **Q: 如何手动触发定时任务?**
- **A**: 访问 `/api/admin/jobs/{jobId}/trigger` 接口，需要管理员权限。
